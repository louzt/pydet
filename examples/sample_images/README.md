# Face Detection Examples

Este directorio contiene imágenes de ejemplo para probar la detección de rostros.

## Instrucciones

Para probar la detección de rostros:

1. Coloca imágenes en este directorio
2. Ejecuta el script de detección:
   ```bash
   python src/face_detection_image.py --image examples/sample_images/tu_imagen.jpg
   ```

## Formatos soportados

- JPEG (.jpg, .jpeg)
- PNG (.png)
- BMP (.bmp)
- TIFF (.tiff)

## Notas

- Las imágenes deben contener rostros frontales para mejores resultados
- Se recomienda que los rostros tengan al menos 30x30 píxeles
- La iluminación adecuada mejora la precisión de la detección
